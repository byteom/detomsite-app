# Shared read cache (app/core/redis_cache.py). Two transports, both supported:
#   * Upstash / Vercel KV REST — KV_REST_API_URL + KV_REST_API_TOKEN, spoken
#     over httpx (already a dependency above).
#   * Raw RESP — REDIS_URL=rediss://… for Render Key Value / Redis Cloud /
#     Railway / self-hosted. That transport needs the client below.
# With neither configured, app/core/embedded_redis.py boots a real redis-server
# inside the process on a unix socket — but only when the `redislite` package
# is installed (it bundles the binary; install it locally with
# `pip install redislite` if you want the embedded cache in dev).
# redislite is intentionally NOT pinned here: it ships no prebuilt wheels for
# newer Pythons, and a source build would fail the Render deploy. The import
# is guarded and every call is best-effort, so without it reads simply fall
# back to the Postgres app_cache table. Set DETOMSITE_EMBEDDED_REDIS=0
# to keep it off explicitly, or supply a real REDIS_URL to shadow it.
